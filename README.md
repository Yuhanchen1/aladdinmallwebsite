# Aladdin Mall website

Static HTML, CSS and JavaScript. No build step required.

## Preview

Run `python3 -m http.server 5173` in this directory.

## Automatic deployment

Import this repository into Netlify or Vercel. Select the main branch, no framework and no build command. Publish the repository root (`.`). Each push to main then triggers deployment.

Login and signup are preview dialogs; no account backend is connected. Store buttons currently link to app store search results.
